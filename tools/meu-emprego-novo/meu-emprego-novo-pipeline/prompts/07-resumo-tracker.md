# Prompt: resumo do tracker

Anexe o `tracker.csv`. Se ele tiver nomes ou contatos de pessoas nas observações, remova antes de anexar.

```
Resuma o tracker.csv anexado no período de [AAAA-MM-DD] a [AAAA-MM-DD].

Mostre:
1. Quantas candidaturas foram enviadas, quantas tiveram resposta e quantas viraram entrevista.
2. Taxa de resposta por versão de currículo (coluna curriculo).
3. Taxa de resposta por fonte (coluna fonte).
4. Candidaturas sem resposta e com próximo passo vencido.
5. Vagas descartadas e os motivos.

Regras:
- Use somente os dados do arquivo; não estime nada.
- Avise quando houver poucos dados para concluir algo.
- Não proponha ações ainda: isso fica para a retrospectiva.
```
