# Contribuindo

PRs e issues são bem-vindos.

**Nunca versione dados pessoais reais** (currículos, `profile_truth.md`, resultados, `.env`).
`input/`, `data/` e `outputs/` estão no `.gitignore`; use `examples/dev_procurando/` para fixtures.

Rode os testes antes de abrir um PR: `python -m unittest discover -s tests -v`
